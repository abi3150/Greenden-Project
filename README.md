# Greenden-Project



**Greenden** is a modern plant e-commerce website built using **HTML** and **Tailwind CSS**. The project focuses on a clean UI, responsive design, and simple navigation to showcase and sell indoor and outdoor plants.

---

## 🏠 Pages Included

### 1. Index Page (Home)

The **Index page** is the landing page of the Greenden website.

**Features:**

* Attractive hero section with plant-themed banner
* Navigation bar with links to all pages
* Featured plants/products section
* Customer-friendly layout with responsive design
* Footer with basic site information and links

---

### 2. Tailwind Implementation

The project uses **Tailwind CSS** for styling.

**Highlights:**

* Utility-first CSS framework
* Faster UI development
* Fully responsive design (mobile, tablet, desktop)
* Clean and modern layout using flexbox and grid
* Easy customization with Tailwind classes

---

### 3. Product Page

The **Product page** displays available plants for purchase.

**Features:**

* Grid layout of plant items
* Each product includes:

  * Image
  * Name
  * Price
* Hover effects for better user interaction
* Responsive product cards

---

### 4. Contact Page

The **Contact page** allows users to connect with the store.

**Features:**

* Simple contact form (Name, Email, Message)
* Clean and minimal design
* User-friendly input fields
* Footer with additional contact details

---

## 🎯 Project Goals

* Build a responsive plant shop website
* Practice **HTML structure** and **Tailwind CSS styling**
* Improve UI/UX design skills
* Create a beginner-friendly e-commerce layout
